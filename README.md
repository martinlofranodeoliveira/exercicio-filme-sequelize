# Catálogo de filmes — exercício com Sequelize

Projeto educacional Node/Express com views EJS e acesso a banco via Sequelize. Não há implantação ou banco de demonstração provisionado.

**Estado:** projeto educacional/legado; avalie código e dependências antes de iniciar.

## Começar em português

**Requisitos:** Node.js, npm e um banco de desenvolvimento configurado pelo usuário.

```sh
git clone https://github.com/martinlofranodeoliveira/exercicio-filme-sequelize.git
cd exercicio-filme-sequelize
npm ci --ignore-scripts
# Revise a configuração do banco e src/app.js antes de iniciar.
```

Use um ambiente de desenvolvimento separado. Não envie `.env`, chaves, bancos,
uploads ou dados pessoais ao Git. Nas demonstrações, use somente dados fictícios.
